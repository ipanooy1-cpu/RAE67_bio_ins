# เว็บจำลองหุ่นโคมไฟน้องคูก้า

ปรับ H และ CPG ดูกราฟและ Export CSV

## วิธีเปิด

ติดตั้ง Node.js แล้วเปิดโฟลเดอร์นี้ใน VS Code รัน npm install ตามด้วย npm run dev เปิดลิงก์ Local เลือก Kuka Simulator และกดเริ่ม
