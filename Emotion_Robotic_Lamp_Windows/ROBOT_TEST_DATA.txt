7. CALIBRATION RULES
--------------------
นิยามค่าที่ต้องเก็บต่อหนึ่ง joint:
- current_raw       = ตำแหน่งที่อ่านได้ก่อนเปิด torque
- center_raw        = ตำแหน่งศูนย์เชิงกล/ท่า neutral
- home_raw          = ตำแหน่งที่ต้องการหลังเริ่มระบบอย่างปลอดภัย
- min_raw_safe      = ค่าต่ำสุดที่ไม่ชนโครง
- max_raw_safe      = ค่าสูงสุดที่ไม่ชนโครง
- direction         = +1 หรือ -1 เพื่อแปลง raw เป็น ROS angle
- max_step_raw      = ระยะขยับสูงสุดต่อหนึ่งคำสั่งในช่วงทดสอบ
- max_speed_raw     = ความเร็วสูงสุดที่ทดสอบแล้วว่าปลอดภัย
- backlash_raw      = ระยะฟรีของเฟืองโดยประมาณ

สูตรแปลง nominal สำหรับสร้างโค้ดภายหลัง:
nominal_rad_per_count = PI / 1024
angle_rad = direction * (raw - center_raw) * nominal_rad_per_count
raw = center_raw + direction * round(angle_rad / nominal_rad_per_count)
ก่อนส่ง raw ต้อง clamp ให้อยู่ระหว่าง min_raw_safe และ max_raw_safe เสมอ

หมายเหตุ:
- สูตรนี้ใช้ได้หลังจากวัด center_raw และ direction แล้วเท่านั้น
- ต้องตรวจองศาจริงกับเครื่องมือวัดก่อนใช้ควบคุมความแม่นยำสูง

16. REQUIREMENTS FOR FUTURE GENERATED CODE
------------------------------------------
AI ที่สร้างโค้ดควรทำตามลำดับนี้:

Phase A - Hardware diagnostic บนคอม
- เปิดพอร์ตจาก config ไม่ hard-code COM8 เพียงค่าเดียว

- แสดงข้อมูลโดยไม่ขยับ Servo เป็นค่าเริ่มต้น

- บันทึกผลกลับมาให้ผู้ใช้กรอกในไฟล์นี้

Phase B - Safe calibration tool
- เลือก Servo ได้ทีละ ID
- ตั้ง target เป็น raw_count รอบ present position
- clamp target ตามค่าที่คาลิเบรตแล้ว
- จำกัด step และ speed
- มี emergency stop
- ห้ามทดสอบ ID ที่ไม่มีค่า safe limits หลังขั้น calibration เริ่มต้น

Phase C - Raspberry Pi driver
- ใช้ device path ที่ตรวจพบจริงบน Pi
- โหลด ID, center, direction และ limits จากข้อมูลในไฟล์นี้หรือ config ที่แปลงจากไฟล์นี้

- ไม่เคลื่อนเมื่อเริ่ม node จนกว่าจะได้รับ enable

Phase D - ROS 2 integration
- รับ target joint angles หน่วย radian
- แปลง radian เป็น raw_count ด้วย calibration ของแต่ละ joint
- publish feedback จาก Servo จริงเป็น sensor_msgs/JointState
- เชื่อมกับ /lamp/cpg_offsets และ motion controller เดิม
- รองรับ safe shutdown และ torque-off เมื่อ node ปิด
